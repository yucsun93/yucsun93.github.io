# Yu-Chen Sun

Personal academic website: [yucsun93.github.io](https://yucsun93.github.io/).

## Pages

- `index.html`: biography, affiliation, contact and education.
- `research.html`: published articles and preprints, with DOI and arXiv links.
- `talks.html`: forthcoming visits and selected past talks.
- `teaching.html`: teaching and academic service.

The former `cv.html` address redirects to the homepage. The CV section was removed because the information is covered by the other pages.

The site uses plain HTML and CSS and requires no installation or build step. All assets are stored in this folder. Edit the relevant HTML page and commit the change to update the website.

GitHub Pages publishes the `main` branch from the repository root. Bibliographic and career information is based on the CV updated 24 September 2026.
